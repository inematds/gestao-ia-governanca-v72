Lesson 4 · 20 min

The agent's indicators

The Hora dashboard shows requests going up, and Carlos concludes it is paying for itself. The dashboard only measures volume: it doesn't tell you whether Hora got it right, how much each request cost, or how much human work is still needed. In this lesson you replace that dashboard with five agent indicators, each with a numerator, a denominator, a baseline and a limit that triggers an action.

Start the lesson

In this lesson you will

  1. 1What is missing in each column of a volume dashboard
  2. 2The agent's 5 indicators: quality, time, cost, autonomy and intervention
  3. 3Baseline when the "before" was never measured
  4. 4Limits that trigger action, and the indicator that improves when the agent gets worse

Goal: track the agent on a 5-indicator dashboard with numerator, denominator, baseline and limit, fixing the dashboard that only shows volume.

02 · From the volume dashboard to the agent dashboard

The lab's F11 was already fixed in G2 with three process indicators. Here the topic is the agent.

1. What each column does not show

The lab dashboard has four columns. Conversations is volume: it goes up with a promotion, the time of year, or too much discount. Orders closed has no before and no comparison. Average satisfaction comes from a button that about 6% of customers answer.

Response time measures the speed of the first message, not of the order. No column tells you whether Hora got it right, how much it cost, or how much human work it created.

Test for each columnDoes this number change if Hora gives a wrong discount? If it doesn't, it's no good for governing the agent.

2. Baseline without the before

Data collection started on the same day Hora came in, in July. The "before Hora" was never measured and can't be measured now. What you can do: measure four weeks of the current version and use that as the baseline against which every change will be compared.

Estimates of the before (like the 8 to 12 minutes per order from G4) remain estimates and show up that way on the dashboard, never as observed.

At HorizonteBaseline: Hora v2.1, four weeks, 3,600 conversations and 680 orders completed. Every dashboard value states the period and the n.

3. Limit that triggers action

Each indicator gets a limit and a defined action for when it is crossed. Quality below 90% in a week: the sample doubles and the cause goes into the weekly review. One critical error: the action goes back to yellow right away and an incident is opened.

The limits are a decision for whoever is accountable for the operation, looking at the baseline. Write them before you need them.

At Horizontep95 of time above 6 h: look at the approval queue. Cost above R$ 7.50 in the month: review. Intervention above 6 min per order: see where the hours went.

4. The indicator that misleads

If the target is "raise autonomy", the fastest way is for Hora to stop asking for approval. The number gets better and the operation gets worse. That's why autonomy and intervention are only read next to quality and critical errors.

In the Work Trend Index 2025, Microsoft proposed the human-agent ratio metric: the balance between human oversight and agent efficiency. It's a vendor proposal; your dashboard measures that balance with indicators 4 and 5.

Question for each indicatorHow does this number improve without the operation improving? If the answer is easy, it needs a pair that watches over it.

  • Indicator without a denominator. "12 conversations taken over" says nothing without the total.
  • Critical error in the average. The error that costs money disappears inside 99%.
  • Average time. One stuck order pulls the average; use median and p95.
  • Autonomy as a target. It goes up when the agent stops asking for help.
  • Estimate as observed. The before that nobody measured shows up as estimated, always.

04 · Practice

Hora's dashboard for practice; your agent's for real.

1 · Hora's dashboard

30 min

Open the lab panel and write, for each of the 4 columns, what it measures and what it does not show. Then build Hora's panel from the template, using the baseline numbers from this lesson, and fill in the indicator sheet for number 4 (autonomy) with the pair that watches it.

Done when: the 4 columns of the lab panel have "measures" and "does not show"; the panel has the 5 indicators with numerator, denominator, baseline with n, limit with action, and owner; critical errors appear outside any percentage; and the autonomy sheet says which indicator watches it.

2 · Your agent's panel

45 min

Build your agent's panel with the 5 indicators. Write down where each number comes from and who pulls it. Start the 4-week baseline collection, changing nothing in the agent during that period, and mark everything from before as estimated.

Done when: the panel is saved with the 5 sheets; each current value is marked as observed (with n and period) or estimated (with the source); the date the 4 weeks end is on the calendar; and the prompt "how this indicator misleads" has been run and answered.

Lab piece: Hora dashboard (F11).

06 · Summary

Five fractionsQuality, time, cost, autonomy, and intervention, each with a denominator.
Critical errors apartCounted outside the averages, with its own action.
BaselineFour weeks measured now; the earlier period only as estimated.
Limit and pairEvery indicator has a limit with an action and another indicator that watches it.
